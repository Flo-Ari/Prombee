# 0.9.24 更新指南

在 GitHub 下载 0.9.24 中适合系统的文件，或使用“设置 → 更新”。安装前保存内容并退出旧进程，安装完成后重新打开。以下本地指令适用于项目输出目录，也可将路径替换为下载文件所在位置。

## Fedora / Red Hat 系列

在终端运行：

```bash
cd /home/casm/Projects/Prombee/dist/local-0.9.24
sudo dnf install ./Prombee-0.9.24-Linux-RedHat-noarch.rpm
```

确认安装后，从应用菜单打开“提示蜂”。输入管理员密码属于本次主动安装操作。

## Debian / Ubuntu 系列

```bash
cd /home/casm/Projects/Prombee/dist/local-0.9.24
sudo apt install ./Prombee-0.9.24-Linux-Debian-all.deb
```

## Linux 便携版

```bash
cd /home/casm/Projects/Prombee/dist/local-0.9.24
chmod +x ./Prombee-0.9.24-Linux-x86_64-Portable
./Prombee-0.9.24-Linux-x86_64-Portable
```

便携版需要系统具有相应的 GTK、WebKitGTK 运行库；优先使用对应系统的安装包，由包管理器处理依赖。

## Windows

下载 `Prombee-0.9.24-Windows-x64-Setup.exe`，运行并选择原安装位置即可更新。便携版下载 `Prombee-0.9.24-Windows-x64-Portable.exe`，退出旧进程后替换原文件。

## 保留原有内容

更新时保留原来的词集文件和用户数据文件夹。如果启动时要求选择数据位置，请选择之前使用的文件夹以继续原有内容。无需删除旧词集或清除用户数据。

## 后续软件内更新

1. 联网启动软件后，会在后台检查版本并下载、校验更新包。此阶段只缓存，不安装，也不会请求管理员密码。
2. 有更新时，“设置”按钮与其中的“更新”标签右上角出现红点，悬停可查看版本及缓存状态。
3. 打开“设置 → 更新”，主动点击“更新并重启”。只有此时才开始安装，系统可能要求授权。
4. 更新完成后红点消失。仅查看更新页面不会清除红点。

已验证的缓存会在重启后复用；发现更新的版本时，会替换旧缓存。此流程以 GitHub 已发布版本为准，本地未发布版本不会自动出现在更新列表中。

## 本次编辑调整

- 序号类型中的“全部”选项会保存为当前编辑页的状态，并在下拉框及选项中高亮。
- “局部”选项只执行一次，不保留高亮，也不会改变“全部”状态。
- 应用跳转目标下拉框使用独立的固定长度虚线，避免宽度变化时虚线被拉伸。

## 默认值及卸载

未设置时，“应用跳转”和“排除空项”默认开启；已保存的关闭状态会保留。应用跳转未选目标时，复制仍正常完成，不会跳转。默认添加为 Ctrl+Q，收放条目为 Ctrl+E，自定义快捷键保留。

RPM、DEB 安装后可从应用菜单选择“卸载提示蜂”。本目录另附 Linux、Windows 卸载工具，便携版将对应工具放到程序旁运行；卸载保留用户数据，详见 [卸载说明](UNINSTALL.md)。

## 本次调整

- 首次自动在软件目录 `data` 中创建临时词集；重启恢复词集列表、当前词集、轮次、编辑标签页、光标及滚动位置。优先沿用已有数据，不迁移或覆盖旧词集。
- 系统安装目录不可写时，自动使用用户应用数据目录（Linux 为 `$XDG_DATA_HOME/prombee/data`，未设置时为 `~/.local/share/prombee/data`；Windows 为 `%LOCALAPPDATA%/Prombee/data`）。已有该目录下的旧词集注册表会优先复用。选择过的位置通过独立启动记录保存，升级不会重置。

- 关闭时自动尝试保存；失败时尝试保留用户数据目录中 `recovery/恢复草稿-*.txt`，随后仍退出。保存等待约 4 秒、恢复副本约 2 秒，桌面宿主另有 8 秒超时保护。磁盘不可写或本机服务中断时恢复副本也可能失败，可用时保留浏览器本地草稿。

- 悬浮球仅在最小化时出现；切换应用、页面或窗口失去焦点不再弹出。

## 已包含的修复

- “文件”页和词集下拉框均可创建临时词集，无需选择保存位置。词集直接保存在当前数据目录内的 `临时词集N.txt`；开发版、便携版默认数据目录为软件旁的 `data`，系统安装版按上述规则选择或复用数据目录。关闭软件后仍保留，名称冲突自动递增。
- 修复较大词集保存请求失败。保存失败时显示具体原因；手动保存或切换词集时，可选择新文件名另存恢复副本，保留原文件。
- 新用户默认开启应用跳转、排除空项，已有明确选择不变。添加为 `Ctrl+Q`，收放为 `Ctrl+E`；原默认快捷键自动迁移，自定义及冲突绑定保留。
