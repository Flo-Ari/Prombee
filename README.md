# 提示蜂

轻量级桌面提示词编辑器，让项目每一轮迭代的要求都有条理、可复用、可对比。

## 使用场景

用于与 AI 智能体协作进行项目迭代：提交本轮任务后，在等待智能体处理时继续整理下一轮提示词，而不是拿起手机消磨时间。随手记录发现的问题、补充约束，再复制给智能体，保持工作思路连贯。

## 具体功能

- **词集管理**：每个词集保存为一个 `.txt` 文件，可新建、打开、重命名并快速切换。用分组整理词集，支持置顶和长按排序；调整分组不改变 TXT 保存位置，默认提供“未分组”。
- **按轮次编写**：自动命名为“第 N 轮”，新建时沿用模板的 Markdown 标题层级。在“新建”右边点“− 删除”可删除本轮并撤销恢复，新建轮次按剩余轮次的最大序号加一命名，全部删除后从第 1 轮重新开始。
- **层级编辑**：H1–H6 标题、自动有序列表、层级折叠、字体、字号、颜色、粗体和斜体；支持多选批量排除与删除，以及撤销、重做和整篇删除空项。切换标签页会保留各编辑器的光标、选区、多选和滚动位置。每行加号可添加正文或 H1–H6 条目，“条目等级”可随时转换。拖动左侧标识或长按条目可连同子条目排序。
- **直接写 Markdown**：内容中已有的 Markdown 优先保留；标题等级仅影响当前层级及其子层级，到同级或上级时恢复。重复或冲突的内容均保留，不自动合并、覆盖或删除。
- **模板**：像编辑提示词一样编辑模板，也可从历史轮次复制标题层级，包含已排除的层级。
- **历史对比与预览**：选择两轮左右对比；预览即将复制的内容，并可切换原始 Markdown。
- **常用提示词**：集中保存可复用内容，逐项复制当前条目及其子层级，或用“全部复制”复制整页，均包含 Markdown 层级。
- **选择复制范围**：用眼睛按钮控制条目是否参与复制，关闭标题时连同下级一起排除；复制时自动略过没有正文的标题分支，保留有正文子级的父标题。
- **语言名称**：中文环境显示“提示蜂”，英文环境显示“Prombee”。
- **窗口操作**：最小化直接收起为蜜蜂悬浮球，也可最大化 / 还原、关闭。
- **桌面悬浮球**：点击最小化或顶部“悬浮球”按钮立即切换为机械蜜蜂，点击蜜蜂立即返回编辑器，支持系统原生拖动。蜜蜂直接使用指定原图的像素，保留原有银黑装甲、蓝色能量装置、蜂巢纹发光翼和弯曲口器；通过原图部件绑定实现动画，未重新绘制造型，持续振翅、眼球跟随整个屏幕的鼠标，伴有随气流漂过的碎片；一分钟未点击会轮流播放四足外骨骼除虫、带 ZZZ 与粉红脸颊的休眠、口器吸取机械花蕊 token、蜂针局部碎屏四种待机动画，场景从当前飞行姿态平滑接入，结束后平滑返回。右键可选择向左或向右飞行，方向会自动记住；也可隐藏、取消动画变为静态 Logo，或单独播放各场景。隐藏后可从任务栏恢复编辑器。Linux 桌面悬浮球通过 X11 / XWayland 运行。
- **快捷键**：在“快捷键”页按编辑区、窗口栏、顶部栏、编辑工具栏与状态栏分区设置并保存；按钮悬停显示名称和当前快捷键。默认 Ctrl+N 打开添加菜单，1–6 立即创建对应等级的条目，↑↓ 选择、Enter 确认，直接 Enter 添加正文；Ctrl+Shift+N 新建一轮。上下方向键切换可见条目；Ctrl+Shift+G 开始排序，↑↓ 移动，Enter 完成，Esc 取消。
- **页面跳转**：右下角按滚动位置显示到顶部、到底部按钮；内容不足一屏时隐藏，支持平滑跳转。
- **语音输入**：优先使用浏览器在线识别，不可用时尝试设备已有的系统听写。
- **本地保存**：自动保存轮次、模板和常用提示词；提供蓝白与黑纸白字主题。

以纯文字复制和分享，与记事本兼容。字体、字号和颜色只影响编辑显示，复制时保留 Markdown 标题、列表及强调标记。

## 安装方法

在 [下载页面](https://github.com/Flo-Ari/Prombee/actions) 选择最新成功的 **Windows desktop**、**Debian package** 或 **Fedora package**，下载对应文件并解压。下载 GitHub Actions 附件需要登录 GitHub。

### Windows 10 / 11

下载 **Prombee-Windows-x64**，解压后双击 `Prombee.exe`，无需安装 Python 或 Node.js。如果提示缺少运行组件，请安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

### Ubuntu 24.04

下载 **Prombee-Debian**，解压后安装 `.deb`：

```bash
sudo apt install ./prombee_0.9.2_all.deb
```

安装后，从应用菜单打开“提示蜂”。

### Fedora 44

下载 **Prombee-Fedora** 并解压，在 RPM 文件所在文件夹打开终端，安装一次：

```bash
sudo dnf install ./prombee-0.9.2-1.fc44.noarch.rpm
```

之后按 Super 键搜索 **提示蜂** 打开，也可在终端输入 `prombee`。安装包会通过 Fedora 仓库安装所需的 GTK、WebKitGTK 和 XWayland 依赖。

如果使用 Linux 单文件版，请先在“属性 → 权限”中允许执行，或在文件所在目录运行 `chmod u+x ./Prombee-0.9.2`，再运行 `./Prombee-0.9.2`。`.exe` 适用于 Windows，`.deb` 适用于 Debian / Ubuntu。

打不开时请在终端运行 `prombee`（安装版）或 `./Prombee-0.9.2`（单文件版）查看报错。Linux 单文件版仍依赖系统图形运行库；不同发行版应选择对应安装包。

### 提示词保存位置

每个词集的轮次、模板和常用提示词都在一个 UTF-8 `.txt` 文件中，可用记事本查看。新建词集时，先选择设备上的保存文件夹；将这个 TXT 文件复制到其他设备，即可重新打开完整词集。

文件包含轮次和条目的文本标记，用于保留层级、显示格式与复制范围。直接改动 TXT 前建议保留副本；复制按钮输出的是整理后的提示词，不包含这些保存标记。

旧版内容首次打开时迁移为 `当前词集.txt`，原 `workspace.json` 保留为备份。默认迁移目录：Windows 为 `%LOCALAPPDATA%\Prombee`，Ubuntu 为 `~/.local/share/prombee`，Linux 单文件版为程序旁的 `Prombee-data`。

词集管理中的“删除”只移除列表记录，原 TXT 文件仍可通过“打开文件”重新打开。旧版已移除的词集文件保留在原数据目录的 `Trash` 文件夹，旧索引保存在 `library-v1-backup.json`。关闭标题左边的三角只折叠显示，眼睛按钮才控制是否参与复制。
