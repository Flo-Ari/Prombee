# Prombee · 提示蜂

轻量级桌面提示词编辑器，让项目每一轮迭代的要求都有条理、可复用、可对比。

## 使用场景

用于与 AI 智能体协作进行项目迭代：提交本轮任务后，在等待智能体处理时继续整理下一轮提示词，而不是拿起手机消磨时间。随手记录发现的问题、补充约束，再复制给智能体，保持工作思路连贯。

## 具体功能

- **词集与项目**：新建词集时选择保存位置，每个词集保存为一个 `.txt` 文件；项目就是文件夹，可新建或选择现有文件夹，将词集加入项目。支持最近词集切换、打开、重命名和回收站恢复。
- **按轮次编写**：自动命名为“第 N 轮”，新建时沿用模板的 Markdown 标题层级。可删除本轮并撤销恢复，新建轮次按剩余轮次的最大序号加一命名，全部删除后从第 1 轮重新开始。
- **层级编辑**：H1–H6 标题、自动有序列表、层级折叠、字体、字号、颜色、粗体和斜体；支持多选批量排除与删除，以及撤销、重做和整篇删除空项。每行的加号可添加条目或任意等级的标题，菜单提示当前所在层级。
- **直接写 Markdown**：内容中已有的 Markdown 优先保留；标题等级仅影响当前层级及其子层级，到同级或上级时恢复。重复或冲突的内容均保留，不自动合并、覆盖或删除。
- **模板**：像编辑提示词一样编辑模板，也可从历史轮次复制标题层级。
- **历史对比与预览**：选择两轮左右对比；预览即将复制的内容，并可切换原始 Markdown。
- **常用提示词**：集中保存可复用内容，逐项复制当前条目及其子层级，或用“全部复制”复制整页，均包含 Markdown 层级。
- **选择复制范围**：用眼睛按钮控制条目是否参与复制，关闭标题时连同下级一起排除。
- **桌面悬浮球**：标题栏最小化按钮左侧可收起为蜜蜂，点击蜜蜂在 0.5 秒内展开编辑器，支持拖动。蜜蜂持续振翅、眼球跟随鼠标，伴有花瓣和草籽；一分钟未点击会轮流播放机甲除虫、休息睡觉、机械花蕊充能、蜂针碎屏四种待机动画。右键可隐藏、取消动画变为静态 Logo，或单独播放各场景。隐藏后可从任务栏恢复编辑器。Linux 桌面悬浮球通过 X11 / XWayland 运行。
- **本地保存**：自动保存轮次、模板和常用提示词；提供蓝白与黑纸白字主题。

以纯文字复制和分享，与记事本兼容。字体、字号和颜色只影响编辑显示，复制时保留 Markdown 标题、列表及强调标记。

## 安装方法

在 [下载页面](https://github.com/Flo-Ari/Prombee/actions) 选择最新成功的 **Windows desktop** 或 **Debian package**，下载对应文件并解压。下载 GitHub Actions 附件需要登录 GitHub。

### Windows 10 / 11

下载 **Prombee-Windows-x64**，解压后双击 `Prombee.exe`，无需安装 Python 或 Node.js。如果提示缺少运行组件，请安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

### Ubuntu 24.04

下载 **Prombee-Debian**，解压后安装 `.deb`：

```bash
sudo apt install ./prombee_0.7.0_all.deb
```

安装后，从应用菜单打开“Prombee · 提示蜂”。

### Fedora 44 x86_64

使用对应的单文件程序 `Prombee`，赋予运行权限后双击打开。Linux 不同发行版请选用对应版本。

### 提示词保存位置

每个词集的轮次、模板和常用提示词都在一个 UTF-8 `.txt` 文件中，可用记事本查看。新建词集或项目时，先选择设备上的保存文件夹；将这个 TXT 文件复制到其他设备，即可重新打开完整词集。

文件包含轮次和条目的文本标记，用于保留层级、显示格式与复制范围。直接改动 TXT 前建议保留副本；复制按钮输出的是整理后的提示词，不包含这些保存标记。

旧版内容首次打开时迁移为 `当前词集.txt`，原 `workspace.json` 保留为备份。默认迁移目录：Windows 为 `%LOCALAPPDATA%\Prombee`，Ubuntu 为 `~/.local/share/prombee`，Linux 单文件版为程序旁的 `Prombee-data`。

“删除”将词集移入本机词集回收站，可在“新建词集”页面恢复。关闭标题左边的三角只折叠显示，眼睛按钮才控制是否参与复制。
