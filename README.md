# 提示蜂

轻量级桌面提示词编辑器，让项目每一轮迭代的要求都有条理、可复用、可对比。

## 使用场景

用于与 AI 智能体协作进行项目迭代：提交本轮任务后，在等待智能体处理时继续整理下一轮提示词，而不是拿起手机消磨时间。随手记录发现的问题、补充约束，再复制给智能体，保持工作思路连贯。

## 具体功能

- **文件**：每个词集保存为一个 `.txt` 文件，可新建、打开、重命名并快速切换。点击词集名称直接改名，可分组、跳转和另存为独立副本。用分组整理词集，支持置顶和长按排序；调整分组不改变 TXT 保存位置，默认提供“未分组”。
- **按轮次编写**：自动命名为“第 N 轮”，新建时沿用模板的 Markdown 标题层级。上一轮没有正文的标题自动折叠，并连同子层级移至父层级末尾；可在“设置 → 其他”关闭自动排序。在轮次切换右边点“−”可删除本轮并撤销恢复，新建轮次按剩余轮次的最大序号加一命名，全部删除后从第 1 轮重新开始。
- **层级编辑**：H1–H6 标题、有序／无序列表和无序号正文（默认无序，支持全部／局部有序、无序和取消序号；在标题上选择局部选项会作用于其下全部正文）、层级折叠、字体、字号、颜色、粗体和斜体；支持多选批量排除与删除，以及撤销、重做和整篇排除空项。切换标签页会保留各编辑器的光标、选区、多选和滚动位置。每行加号可添加正文或 H1–H6 条目，“条目等级”可随时转换。拖动左侧标识或长按条目可连同子条目排序。
- **附件**：编辑区上方的附件画廊可用系统文件选择器添加图片、视频、代码和文档。直接粘贴附件会在条目光标处插入本地引用；超过 2 万字的代码围栏转为 TXT 附件。复制提示词时，桌面剪贴板同时提供文字、引用与附件文件，接收应用按自己支持的格式粘贴；浏览器预览版复制文字和附件引用。附件保存在本机用户数据的 `attachments` 目录，更新时保留。
- **显示区**：编辑、预览、历史和设置等显示区共用宽度。拖动两侧边缘调整，跨页、重启和升级后保留。
- **技能补全**：在“设置 → 其他”选择目标智能体，在条目中输入 `$` 搜索本机技能，用方向键和 Enter 选择。支持读取个人、项目和插件技能目录，也可自行选择技能文件夹。选中后插入技能引用文字。
- **文字选择**：鼠标可跨条目选择和复制，剪贴板只包含选中的文字，不附加标题、列表标记或操作按钮文字。H1、H2、H3 默认字号分别为 18、16、14，行框随文字字号调整。
- **工具栏布局**：固定在左侧竖向排列，保持紧凑，为正文留出更多空间。
- **直接写 Markdown**：可在“设置 → 其他”选择是否识别条目中的 Markdown。开启时优先保留已有 Markdown；标题等级仅影响当前层级及其子层级，到同级或上级时恢复。重复或冲突的内容均保留，不自动合并、覆盖或删除。
- **模板**：自动跟随最新轮次的标题结构，也可手动编辑或从历史轮次更新层级，包含已排除的层级。
- **历史与预览**：选择两轮左右对比；预览即将复制的内容，并可切换原始 Markdown。
- **剪切条目**：未选中文字时，Ctrl+X 复制当前条目的纯文字并仅删除该条目，子条目保留；已选中文字时使用普通剪切。
- **复制后跳转**：在“设置 → 其他”开启并选择已打开窗口、已安装应用或网页地址，设置自动保存；复制成功后跳转，剪切条目不触发跳转。窗口列表中的浏览器页面以当前标签为准。Linux 窗口列表使用 X11 / XWayland；原生 Wayland 窗口可选择对应应用或网页地址。
- **设置与更新**：点击主题按钮左边的齿轮，进入快捷键、悬浮球或更新页。更新页显示版本，检查后点击“更新并重启”即可下载、校验并安装；Fedora / Debian 可能需要在系统窗口确认管理员授权。
- **复制选项**：“排除空项”是持续开关，开启后复制与预览自动过滤空项，保留编辑区内容。批量“排除”可在排除和不排除之间切换。
- **常用**：集中保存可复用内容，逐项复制当前条目及其子层级，或用“全部复制”复制整页，均包含 Markdown 层级。
- **选择复制范围**：用眼睛按钮控制条目是否参与复制，关闭标题时连同下级一起排除；开启“排除空项”后，复制时略过没有正文的标题分支，保留有正文子级的父标题。
- **语言名称**：中文环境显示“提示蜂”，英文环境显示“Prombee”。
- **顶部栏**：编写、复制、模板、轮次、文件、历史、预览、常用和设置合并到一行；空白处可拖动窗口，右侧保留最小化、最大化和关闭。
- **窗口操作**：启用悬浮球后，最小化收起为蜜蜂悬浮球；关闭时使用普通最小化，也可最大化 / 还原、关闭。
- **桌面悬浮球**：在“设置 → 悬浮球”开启后，最小化或 Alt+Tab 切到其他应用时显示机械蜜蜂，切回编辑器自动收起；开关状态会保存。点击蜜蜂立即返回编辑器，支持系统原生拖动，记住上次停留位置。蜜蜂直接使用指定原图的像素，保留原有银黑装甲、蓝色能量装置、蜂巢纹发光翼和弯曲口器；通过原图部件绑定实现动画，未重新绘制造型，持续振翅、眼球跟随整个屏幕的鼠标，伴有随气流漂过的碎片；一分钟未点击会轮流播放四足外骨骼除虫、带 ZZZ 与粉红脸颊的休眠、口器吸取机械花蕊 token、蜂针局部碎屏四种待机动画，场景从当前飞行姿态平滑接入，结束后平滑返回。右键可选择向左或向右飞行，方向会自动记住；也可隐藏、取消动画变为静态 Logo，或单独播放各场景。隐藏后可从任务栏恢复编辑器。Linux 桌面悬浮球通过 X11 / XWayland 运行。
- **快捷键**：在“快捷键”页按编辑区、窗口栏、顶部栏、编辑工具栏与状态栏分区设置并保存；按钮悬停显示名称和当前快捷键。默认 Ctrl+N 打开添加菜单，1–6 立即创建对应等级的条目，↑↓ 选择、Enter 确认，直接 Enter 添加正文；Ctrl+Shift+N 新建一轮，Ctrl+Shift+D 删除本轮。Ctrl+左右方向键跳到相邻标点右侧。上下方向键先在条目内逐行移动，到首行／末行后进入相邻可见条目；Ctrl+Shift+G 开始排序，↑↓ 移动，Enter 完成，Esc 取消。
- **页面跳转**：右下角按滚动位置显示到顶部、到底部按钮；内容不足一屏时隐藏，支持平滑跳转。
- **语音输入**：优先使用浏览器在线识别，不可用时尝试设备已有的系统听写。
- **成对输入**：中英文引号、括号、反引号自动补齐，光标留在中间；三个反引号可补成代码围栏。在“设置 → 其他”随时开关，自动保存。
- **清除用户数据**：在“设置 → 其他”重置设置、分组和最近记录，确认后执行；保留磁盘上的 TXT 词集及附件，可再次打开。
- **本地保存**：自动保存轮次、模板和常用提示词；提供蓝白与黑纸白字主题。

以纯文字复制和分享，与记事本兼容。字体、字号和颜色只影响编辑显示，复制时保留 Markdown 标题、列表及强调标记。

## 安装方法

在 [下载页面](https://github.com/Flo-Ari/Prombee/releases) 下载最新版本中适合系统的文件。已安装用户可在“设置 → 更新”中更新。

### Windows 10 / 11

下载 `.exe` 文件，双击打开，无需安装 Python 或 Node.js。如果提示缺少运行组件，请安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

### Ubuntu 24.04

下载 `.deb` 文件后安装：

```bash
sudo apt install ./prombee_0.9.12_all.deb
```

安装后，从应用菜单打开“提示蜂”。

### Fedora 44

下载 `.rpm` 文件，在其所在文件夹打开终端，安装一次：

```bash
sudo dnf install ./prombee-0.9.12-1.fc44.noarch.rpm
```

之后按 Super 键搜索 **提示蜂** 打开，也可在终端输入 `prombee`。安装包会通过 Fedora 仓库安装所需的 GTK、WebKitGTK 和 XWayland 依赖。

如果使用 Linux 单文件版，请先在“属性 → 权限”中允许执行，或在文件所在目录运行 `chmod u+x ./Prombee-0.9.12`，再运行 `./Prombee-0.9.12`。`.exe` 适用于 Windows，`.deb` 适用于 Debian / Ubuntu。

打不开时请在终端运行 `prombee`（安装版）或 `./Prombee-0.9.12`（单文件版）查看报错。Linux 单文件版仍依赖系统图形运行库；不同发行版应选择对应安装包。

### 提示词保存位置

每个词集的轮次、模板和常用提示词都在一个 UTF-8 `.txt` 文件中，可用记事本查看。新建词集时，先选择设备上的保存文件夹；将这个 TXT 文件复制到其他设备，即可重新打开完整词集。

文件包含轮次和条目的文本标记，用于保留层级、显示格式与复制范围。直接改动 TXT 前建议保留副本；复制按钮输出的是整理后的提示词，不包含这些保存标记。

旧版内容首次打开时迁移为 `当前词集.txt`，原 `workspace.json` 保留为备份。默认迁移目录：Windows 为 `%LOCALAPPDATA%\Prombee`，Ubuntu 为 `~/.local/share/prombee`，Linux 单文件版为程序旁的 `Prombee-data`。

词集管理中的“删除”只移除列表记录，原 TXT 文件仍可通过“打开文件”重新打开。旧版已移除的词集文件保留在原数据目录的 `Trash` 文件夹，旧索引保存在 `library-v1-backup.json`。关闭标题左边的三角只折叠显示，眼睛按钮才控制是否参与复制。
